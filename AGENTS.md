# Direto (repositório post-machine)

- Leia `docs/STATE.md`, `docs/PRODUCT_SPEC.md` e a fase atual em `docs/ROADMAP.md` antes de editar.
- Trabalhe somente em `main`. Preserve arquivos e comportamentos corretos; não implemente todas as fases de uma vez.
- Custo operacional adicional obrigatório: R$ 0. Sem APIs pagas, banco remoto ou serviços por assinatura.
- React + TypeScript estrito + Vite + Tailwind. Decisões e licenças em `docs/ARCHITECTURE.md`.
- Não simule notícias, métricas, autenticação, IA ou ferramentas não implementadas.
- Nunca publique segredos, conteúdo pessoal ou uploads. Repositório público; dados de projetos serão locais.
- Exclusivamente desktop. Desktop first SEMPRE (instrução do proprietário em 13/11/2026). Não criar layout mobile. Viewport mínimo: 1024 px; abaixo disso, apenas aviso para usar desktop. Testar 1280 e 1440 px.
- Interface em português, acessível por teclado e com estados honestos.
- Antes de concluir: `npm run lint`, `npm test`, `npm run build`; para mudanças de interface, `npm run test:e2e`.
- Atualize `docs/STATE.md` com resultados reais e pendências. Contas e deploy: `docs/SETUP.md`.
- Não copie código das referências sem verificar licença e compatibilidade.
