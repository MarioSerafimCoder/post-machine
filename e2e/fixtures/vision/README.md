# Fotos usadas no teste de classificação local

- `chelsea.png` é uma foto de Stefan van der Walt, CC0. [Origem e licença](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.chelsea)
- `coffee.png` é uma foto de Rachel Michetti, CC0. [Origem e licença](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.coffee)

Os arquivos vêm da versão [v0.25.2 do scikit-image](https://github.com/scikit-image/scikit-image/tree/v0.25.2/skimage/data). O teste usa nomes neutros para comparar o pareamento por metadados com a classificação dos pixels.
